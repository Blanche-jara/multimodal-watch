# 멀티모달 AI · 워치 암기 카드

- [서술형 카드](https://blanche-jara.github.io/multimodal-watch/)
- [연속 스크롤 총정리](https://blanche-jara.github.io/multimodal-watch/cram/): 사이드바 없이 전체 본문을 읽고, 비교표를 세로로 확인할 수 있습니다.

갤럭시 워치처럼 작은 화면에서 읽는 멀티모달 AI 1–4강 복습 페이지입니다.

- 8개 주제, 59개 예상 개념 문제와 서술형 답안
- 정의, 작동 원리, 의의·한계를 이어 쓰는 완결된 문장형 설명
- 터치 목차, 이전/다음 버튼, 좌우 스와이프
- 수식 확대, 글자 크기 조절
- 브라우저 내부 즐겨찾기와 마지막 위치 저장
- 첫 온라인 접속 후 서비스 워커의 오프라인 캐시 지원

## 사용

GitHub Pages 주소를 워치의 Samsung Browser에서 열어 사용합니다.
실제 Galaxy Watch8 하드웨어에서는 아직 검증하지 않았으며, 작은 브라우저 화면에서 검수했습니다.
오프라인 이용 가능 여부는 브라우저의 서비스 워커·캐시 지원에 따릅니다.

## 배포

별도 빌드 없이 `main` 브랜치 루트를 GitHub Pages 소스로 사용합니다.
`index.html`, `sw.js`, `.nojekyll`만으로 동작합니다.

내용은 박관용 교수의 멀티모달 AI 강의 1–4강을 바탕으로 작성한 학습 요약입니다.
원본 강의 PDF와 슬라이드 이미지는 이 저장소에 포함하지 않습니다.
