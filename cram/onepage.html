01 · 기초와 CLIP 1강 / 2강 pp.4–43

Modality=표현·지각 방식. Raw(픽셀/파형)→abstract(객체/의미). 멀티모달 이유: 인간 경험·실제 응용·데이터 확장. Foundation model=대규모 자기지도 사전학습→다양한 downstream task.

Profile: distribution·granularity·structure·information·noise. p17 종합 6축: representations/distributions/structure/information/noise/relevance(과제·문맥). BoW는 순서 소실.

CLIP = Contrastive Language–Image Pre-training

400M image–text pairs. image encoder(ViT/ResNet)+text Transformer(EOT/causal/77)→공통 공간. ViT=patch→linear+pos→Transformer/CLS. 정규화 벡터의 내적=cosine. CLIP은 문장 생성보다 짝 맞추기.

Sij=Ii·Tj/τ (I,T: L2 정규화)
LI→T=−(1/N)Σilog[eSii/ΣjeSij]
LT→I=−(1/N)Σilog[eSii/ΣjeSji]
L=(LI→T+LT→I)/2

N×N: 행=image, 열=text. 대각 양성 N개, 음성 N(N−1)개. 행·열 CE 모두. τ↓→softmax 더 뾰족. 균일 점수면 L=ln N. SimCLR 양성=같은 이미지의 두 view.

Zero-shot / 평가

“a photo of a {class}”→Tk; ŷ=argmaxk I·Tk. 텍스트 특징=분류기 가중치. 여러 템플릿 평균=prompt ensemble. Zero-shot: 타깃 라벨 추가학습 없음. Linear probe: encoder 고정+head 학습. Fine-tune: encoder도 갱신.

02 · 강건성·SigLIP·한계 2강 pp.45–72

Effective robustness: 원래 분포 성능을 감안한 shift 저항. 통제 실험의 핵심 원인=학습 데이터 분포. 언어 감독·규모·prompt·대조 손실만으로 설명 X. 혼합 강건성은 가산 X, 분포 사이 보간. R(YFCC)<R(혼합)<R(LAION).

SigLIP = 쌍별 sigmoid 이진 손실

zij=+1(짝), −1(비짝); sij=t Ii·Tj−b
L=(1/B)Σi,jlog[1+exp(−zijsij)]
b 부호: 2강 p.59 원본 기준; t,b 학습 가능.

배치 전역 softmax 분모 없음→분할/분산·메모리 효율. 음성쌍은 여전히 필요. 작은 batch에서 유리, 큰 batch에서 유사한 경향.

장점: 싼 내적→검색·확장, open vocabulary.
한계: 관계/세부 개념→hard negatives; 이미지 전체 캡션의 지역성 부족→region caption+box.

DataComp=데이터 필터 중요, 큰 데이터≠항상 좋음. Meta CLIP 2=다국어 확장. Perception Encoder=좋은 특징은 중간 층에도 존재.

03 · 적은 데이터로 CLIP 적응 3강 pp.4–54

Engineering=사람이 문구 선택. Learning=연속 prompt 벡터 학습. 작은 데이터의 무작정 full FT는 과적합 위험. Frozen 가중치도 gradient 경로는 통과 가능.

방법변경/학습 대상핵심
CoOptext context v1:M고정 문맥, base 과적합
CoCoOpcontext+Meta-Net이미지별 문맥, 느림
Pixel공통 픽셀 패턴입력 공간, 전 이미지 공통
VPTvisual tokens+head임베딩 공간 shallow/deep
MaPLe양쪽 deep prompt+Ftext→vision coupling
Tip-Adapterfeature/label cache추가 gradient 학습 없음
FLYPimage+text encoder둘 다 FT, 대조 목표 유지

CoOp·CoCoOp·Pixel·VPT·MaPLe는 pretrained backbone 동결. VPT는 task head도 학습. Tip은 labeled few-shot 데이터 필요.

CoOp / CoCoOp / MaPLe를 혼동하지 않기

CoOp: tk=[v1…vM, CLASSk]. image/text encoder 고정, 문맥만 class CE로 학습. 길이 이득 체감·자연어 해석 어려움. 도메인 전이≠novel class 일반화.

CoCoOp: π=hθ(f(x)), vm(x)=vm+π
p(k|x) ∝ exp[cos(f(x),g(tk(x)))/τ]

Meta-Net이 이미지 특징에서 조건부 토큰 생성. novel/전이↑, 이미지마다 text encoding→느림. MaPLe: vision+language 여러 층 prompt, PlV=Fl(PlT), F=linear projection. CoCoOp는 image→text, MaPLe는 text prompt→vision prompt.

VPT: shallow=첫 층 입력만, deep=여러 층. FLYP: label→caption, 사전학습과 같은 image–text contrastive objective로 전체 FT. image+linear head class CE와의 mismatch 줄임.

Tip: query=test 특징, key=few-shot 이미지 특징 F, value=one-hot L. A=exp[−β(1−fFᵀ)], logits=αAL+기존 CLIP logits.

일반화 평가 3축

Base→novel: 같은 dataset의 새 클래스. Cross-dataset: 다른 dataset. Domain generalization: 같은 과제의 분포 변화. 균형 지표 HM=2BN/(B+N)(보충식).

04 · Open-vocabulary detection 3강 pp.55–65

Image 분류→region 탐지→pixel 분할. ViLD=Vision and Language Knowledge Distillation. Class-agnostic localization과 언어 기반 classification 분리.

ViLD-Text: region↔base text embedding, CE.
ViLD-Image: region feature가 CLIP crop feature를 모방, L1 distillation.
Region feature L2 정규화와 L1 loss 구별.

추론: region↔base+novel text 비교. 새 카테고리는 text embeddings 교체. LVIS rare=novel, APr 평가. 색·속성으로 어휘 확장.

Learning to Name Classes=문맥 대신 클래스명 표현 최적화. HPS v2=생성 이미지의 사람 선호 학습·예측·평가.

05 · Transformer·Tokenizer 4강 pp.6–27

Transformer layer=attention+FFN+LayerNorm+residual. Decoder는 미래 누출을 causal mask로 차단.

Attn(Q,K,V)=softmax(QKᵀ/√dk+M)V
Mij=0 (j≤i), −∞ (j>i)
p(x1:T)=∏tp(xt|x<t)

미래 score 0만 넣으면 softmax weight≠0. −∞→확률 0. 학습은 mask로 병렬, 생성은 autoregressive 순차. Greedy는 매번 최고 토큰, 전체 최고 문장 보장 X.

문자열→tokenizer→ID→embedding lookup→LM. ID≠의미 벡터. E∈ℝd×|V|, 파라미터=d|V|. 큰 단위: sequence↓/어휘↑. Subword는 word 효율+character coverage 절충, 항상 형태소 X. Zipf: 빈도∝1/순위.

06 · MLLM / LLaVA 4강 pp.30–57

Vision encoder→connector→LLM+instruction. CLIP-ViT-L/14의 penultimate patch tokens→projector→LLM 입력. 초기 projector=linear, 1.5=MLP.

왜 penultimate? 최종 CLS에 대조 감독, 최종 patch output 직접 감독 부족. 공간·세부 보존. 모든 patch가 학습 안 됐다는 뜻 X.

데이터: caption+object/box 텍스트→text-only GPT가 지시·답 생성→(image,instruction,answer). GPT가 raw pixel을 보는 방식 X. Next-token pretrain≠instruction following.

단계VisionProj.LLM
S1 feature alignment동결학습동결
S2 instruction tuning동결학습학습
L=−Σtlog p(at|image,instruction,a<t)

시각 조건 아래 답변 언어 토큰의 AR loss. S1 595K pairs, S2 Instruct-158K(58K 대화/23K 묘사/77K 추론).

07 · Vision의 세 문제 4강 pp.61–94

① Encoder: 강의 이해 과제에서 CLIP/SigLIP가 유리. Multi-crop=고정 encoder로 고해상도; 576→2880 토큰. VCoder=seg/depth 추가.

CLIP-blind pair: CLIP cosine>.95, DINOv2<.6→MMVP. CLIP=의미 강점/세부 약점. MoF는 CLIP+DINOv2 상보적 특징(I-MoF 세부↑).

② Token 비용: attention O(L²).
Q-Former=정한 수 query로 압축.
Concat→projection=이웃 4→1.
PruMerge=중요 sample→kNN cluster→weighted average. 토큰 25%만 사용(25% 감소 X).
UI graph=구조적 중복, selection+원위치 보존.

③ SoM=Set-of-Mark. 의미 region 분할+말로 참조 가능한 mark→grounding. 도구 SEEM/Semantic-SAM/SAM. 작은→큰 region overlay, 이전 region 제외. 가중치 학습보다 입력 표시 방식.

마지막 함정: S2 vision 학습 X / SigLIP 음성 없음 X / Tip 데이터 없음 X / CoOp=CoCoOp X / SoM=VPT 학습토큰 X.
