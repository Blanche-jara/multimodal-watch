1. Modality와 Foundation Model

Modality는 정보가 표현되거나 지각되는 방식이다. 이미지·영상·텍스트·음성·촉각 등 서로 다른 방식의 정보를 함께 다루면 multimodal이다.

왜 여러 모달리티인가? ① 인간의 경험·관찰이 멀티모달이다(faithfulness). ② 인터넷과 실제 응용에 다양한 모달리티가 공존한다(practicality). ③ 대규모 데이터 확보와 확장이 가능하다(data efficiency & availability).

Foundation Model: 대규모 자기지도 사전학습과 범용적·확장 가능한 신경망 구조를 바탕으로, 다양한 downstream task에 적응하는 기반 모델. ‘모델이 크다’만으로 정의하지 말고 대규모 사전학습 → 여러 과제로 전이를 말한다.

3. CLIP 구조와 학습 데이터

CLIP = Contrastive Language–Image Pre-training. 인터넷의 이미지와 연결된 alt-text 등 약 4억(400M) 이미지–텍스트 쌍으로 학습한다. 비싼 고정 클래스 라벨 대신 자연어 설명으로 감독한다.

이미지 x→image encoder f→정규화 I⇄정규화 T←text encoder g←텍스트 t

두 인코더(dual encoder)가 각 모달리티를 같은 차원의 임베딩 공간으로 보낸다. 인코더는 각 모달리티 구조를 처리하고, alignment function은 두 표현이 얼마나 잘 맞는지 비교한다. 대응 쌍은 가깝게, 비대응 쌍은 멀게 학습한다.

  • 이미지 인코더: ResNet 또는 ViT. ViT는 이미지 패치를 펼침 → 선형 투영 → 위치 임베딩 → Transformer. 일반 self-attention을 사용하고 전역 표현에 CLS 등을 사용.
  • 텍스트 인코더: 토큰화한 텍스트 → 임베딩+위치 정보 → Transformer → EOT(end-of-text) 표현 사용. Causal attention, context length 77.
  • CLIP vs SimCLR: CLIP의 양성쌍은 이미지–연결 텍스트, SimCLR은 같은 이미지의 다른 augmentation view다.
  • Captioning과의 차이: 정답 캡션 단어를 순서대로 생성하기보다, 배치에서 어떤 텍스트가 어떤 이미지와 짝인지 예측한다.
함정 “인간 감독이 전혀 없다”보다 수동으로 만든 과제별 클래스 라벨 없이 웹의 자연어 감독을 사용한다고 답한다. CLIP의 출력은 기본적으로 문장 생성이 아니다.

4. 최우선 수식: CLIP의 대칭 InfoNCE

배치에 대응 쌍이 N개 있다. Ii, Tj는 L2 정규화된 벡터로 두고, 유사도 행렬의 행=이미지, 열=텍스트로 고정한다.

Sij = (Ii · Tj) / τ
LI→T = −(1/N) Σi=1…N log [ exp(Sii) / Σj=1…N exp(Sij) ]
LT→I = −(1/N) Σi=1…N log [ exp(Sii) / Σj=1…N exp(Sji) ]
LCLIP = (LI→T + LT→I) / 2
τ: temperature. 정규화 전 표현의 cosine similarity는 z·z′ / (‖z‖‖z′‖). Σ의 범위와 행·열 방향을 확인한다.
  • N×N 행렬의 대각선은 원래 대응하는 양성쌍 N개. 나머지 N(N−1)개를 음성쌍으로 취급한다.
  • 각 이미지가 N개 텍스트 중 짝을 고르고, 각 텍스트도 N개 이미지 중 짝을 고른다. 행 softmax와 열 softmax를 둘 다 쓴다.
  • 손실 최소화는 단순히 모든 유사도를 키우는 것이 아니라, 정답 유사도가 다른 후보보다 높게 되도록 만든다.
  • 작은 τ는 softmax를 더 뾰족하게 한다. 구현의 learnable logit scale은 1/τ 역할이며 표기법이 다를 수 있다.
계산 연습(설명용) N=3이면 점수 9개, 양성 3개, 음성 6개. 모든 후보의 점수가 같으면 정답 확률 1/3, 양방향 평균 손실도 ln 3이다.

5. Zero-shot·프롬프트 앙상블·평가 방식

  1. 테스트할 클래스 이름으로 문장 생성: “a photo of a {class}”.
  2. 각 문장을 텍스트 인코더로 보내 클래스별 벡터 Tk를 만든다.
  3. 테스트 이미지 벡터 I와 각 Tk의 유사도를 계산하고 가장 큰 클래스를 선택한다.
p(y=k | x) = exp(I·Tk/τ) / Σc exp(I·Tc/τ)
ŷ = argmaxk I·Tk

Open vocabulary: 클래스 이름·설명을 바꿔 후보를 정의한다. Prompt engineering은 사람이 문구를 설계하는 것. Prompt ensemble은 클래스마다 여러 템플릿의 텍스트 표현을 평균해 사용한다. 강의 예시는 “a photo of”로 ImageNet +1.3%, 여러 템플릿 앙상블로 약 +5% 효과를 보여 준다(해당 실험 결과).

6. CLIP의 강건성은 어디에서 오는가?

Distribution shift: 학습·평가 분포가 달라지는 것(낯선 시점·스케치 등). Effective robustness는 원래 분포 성능이 높아서 따라오는 효과를 넘어, 분포 변화에서 얼마나 잘 버티는지 보는 관점이다.

강의의 Fang 등의 통제 실험은 ① 데이터 크기 ② 데이터 분포 ③ 언어 감독 ④ 테스트 프롬프트 ⑤ 대조학습 목표를 나눠 조사했다. 주요 결론: 학습 데이터 분포가 중요하다.

  • 같은 데이터에서 CLIP 방식만으로 분류 모델보다 높은 effective robustness가 보장되지 않았다.
  • ImageNet에 캡션을 붙여 CLIP을 학습해도 기존 ImageNet 모델의 경향을 따랐다.
  • YFCC의 다른 학습 방식도 비슷한 강건성 경향을 보였다.
  • 데이터 수·언어 감독·대조 손실·프롬프트 변경만으로 강건성의 원인을 설명하기 어렵다.

데이터를 많이 섞으면 되는가? 아니다. 강건성은 합산되지 않으며 혼합 분포 사이를 보간하는 양상이다. 강의 예: R(YFCC) < R(YFCC+LAION) < R(LAION). 혼합으로 ImageNet 정확도가 올라가도 모든 shift의 강건성이 더 좋아진다고 할 수 없다. 사전학습 모델을 이용한 필터링이 도움이 된다는 분석으로 이어진다.

서술 답안 “언어 감독이 CLIP의 강건성 원인인가?” → 강의의 통제 실험에서는 언어 감독 자체보다 학습 데이터의 분포 선택이 effective robustness를 설명하는 핵심이었다.
범위 위 결론은 강의에서 소개한 실험의 결과다. ‘데이터 크기는 성능과 항상 무관하다’로 일반화하지 않는다.

7. SigLIP: softmax 대신 pairwise sigmoid

CLIP은 배치 전체 후보와 비교하는 softmax 정규화가 필요하다. SigLIP은 각 이미지–텍스트 쌍이 맞는지 독립적인 이진 손실로 학습한다.

zij = +1 (paired), −1 (unpaired)
sij = t (Ii·Tj) − b
L = (1/B) Σi=1…B Σj=1…B log[1 + exp(−zijsij)]
2강 p.59의 −log {1/[1+exp(zij(−t Ii·Tj+b))]}와 같은 식. t와 b는 학습 가능. b는 원본의 부호를 따른다.

10. CoOp: 자연어 문맥을 학습 가능한 벡터로

왜 prompt를 학습하는가? CLIP 전체를 적은 데이터로 단순 미세조정하면 과적합·일반화 손실 위험이 크다. 사람이 문구를 고르는 prompt engineering도 표현을 조금 바꿀 때마다 성능이 달라 어렵다.

a photo of a [CLASS]→[v₁][v₂]…[vM][CLASS]

CoOp = Context Optimization. 문맥 단어를 연속적인 학습 벡터로 바꾼다. 클래스 이름은 유지하고, image/text encoder는 동결하며 context vectors만 학습한다. 정답 클래스의 이미지–텍스트 유사도가 높아지도록 역전파한다.

ti = [v₁, …, vM, CLASSi]
p(y=i | x) = exp[cos(g(ti), f(x))/τ] / Σj=1…K exp[cos(g(tj), f(x))/τ]
f(x): 이미지 특징, g(tᵢ): 클래스 i의 텍스트 특징, K: 클래스 수, τ: temperature. 손으로 고른 문맥 대신 v₁…vM을 최적화한다.
  • 장점: few-shot 적응이 좋고, 다른 이미지 도메인에도 전이되는 모습을 보인다.
  • 한계: 학습한 base 클래스에 특화되어 같은 데이터셋의 novel 클래스에는 성능이 떨어질 수 있다.
  • 긴 context는 성능을 높이지만 추가 이득은 감소한다. 강의 실험에서 초기화 영향은 작았다.
  • 학습 벡터와 가까운 단어 일부는 의미가 있어도 전체 prompt가 자연어로 해석되지는 않는다.
함정 “도메인 전이가 좋다”와 “새 클래스에 과적합한다”는 모순이 아니다. 도메인 변화와 클래스 변화는 다른 평가다. Encoder 동결은 가중치 업데이트를 막는 것이며, prompt로의 역전파까지 막는 것은 아니다.
예상 단답 “CoOp의 학습 대상과 한계는?” → 텍스트 context vectors만 학습하고 CLIP encoders는 고정한다. Base 클래스에 과적합하여 novel 클래스 일반화가 약해질 수 있다.

11. CoCoOp: 이미지마다 다른 문맥

CoCoOp = Conditional Context Optimization. 고정 문맥의 과적합을 줄이기 위해 이미지 특징을 작은 Meta-Net에 넣어 meta-token π를 생성하고, 이를 각 context vector에 더한다.

π = hθ(f(x))
vm(x) = vm + π
ti(x) = [v₁(x), …, vM(x), CLASSi]
p(y=i | x) = exp[cos(g(ti(x)), f(x))/τ] / Σj=1…K exp[cos(g(tj(x)), f(x))/τ]
f(x)를 명시해 이미지 특징과 원시 이미지를 구분했다. 원본 p.20은 특징을 x로 줄여 vₘ(x)=vₘ+hθ(x)로 표기한다.

13. MaPLe: 시각·언어의 깊은 프롬프트를 연결

14. Tip-Adapter: 학습 없이 few-shot 캐시를 더한다

16. ViLD: 위치는 탐지기가, 분류는 언어 지식으로

19. Transformer LM·미래 마스크·자기회귀

Transformer layer의 네 구성은 multi-head attention, feed-forward NN, layer normalization, residual connection이다. Decoder LM의 각 위치는 현재와 과거 위치만 보고 다음 토큰 분포를 계산한다.

pθ(xt | x<t)
eij = qiTkj (j ≤ i),   −∞ (j > i)
softmax(미래 위치의 −∞) = 0
마스크 수식은 p.9 원본 표기. 이 슬라이드에는 √d 스케일이 생략되어 있다.

자기회귀 결합확률: p(x1:T)=∏t=1…Tp(xt|x<t). 매 단계 가장 높은 확률의 토큰을 고르는 greedy 방식이 전체 문장 확률의 최댓값을 보장하지는 않는다.

  • Causal mask: 미래 정답을 보지 못하게 하면서 여러 위치의 학습 계산을 병렬화한다.
  • 자기회귀 생성: 다음 토큰 분포 → 하나 선택 → 문맥에 추가 → 반복. Decoding은 매 단계 후보를 선택하는 탐색이다.
  • 병목: self-attention은 토큰 수 L에 대해 O(L²). 뒤의 이미지 토큰 압축과 연결한다.

21. MLLM의 구조와 visual instruction 데이터 합성

Generalist는 한 모델로 여러 과제를 수행한다. MLLM 구축의 세 요소는 ① instruction-following 데이터 ② pretrained vision·language model ③ cross-modal connector다. 기존 모델을 재사용하고 반자동으로 데이터를 모아 비용을 줄인다.

  1. MLLM에는 (image, instruction, output) triplet이 필요하다.
  2. Text-only GPT에 이미지의 caption 5개 + object categories/bounding boxes를 텍스트 context로 제공한다(MS-COCO).
  3. 수작업 seed 예시와 생성 지시로 GPT가 instruction/output을 생성한다.
  4. 이를 원래 이미지와 묶어 visual instruction triplet으로 만든다.

22. LLaVA가 CLIP의 끝에서 두 번째 층을 쓰는 이유

LLaVA = Large Language-and-Vision Assistant. CLIP의 patch features를 projector로 LLM 입력 공간에 맞추고 text tokens와 함께 넣는다. 이미지 전체의 요약 하나보다 여러 patch tokens가 세부·공간 정보를 전달하기 좋다.

  • 인코더: CLIP-ViT-L/14. Image-text contrastive pretraining으로 언어와 연관된 시각 표현을 갖는다.
  • Projector: 초기 LLaVA는 linear layer, LLaVA-1.5는 MLP.
  • Feature 선택: 최종 CLIP contrastive loss는 CLS를 감독한다. 최종 층 patch outputs는 직접 감독되지 않는다.
  • Penultimate layer: 끝에서 두 번째 층 patch tokens가 LLM에 필요한 공간·언어 정보를 잘 보존한다. CLS를 빼면 소폭 이득 가능.
예상 서술 “왜 최종 CLS나 최종 patch 대신 penultimate patch인가?” → CLS는 전역 요약이라 공간 세부가 부족하고, 최종 patch outputs는 contrastive 목적의 직접 감독이 없다. 앞 층의 patch features가 공간·언어 정보를 더 잘 보존한다.
함정 “CLIP의 patch는 전혀 학습되지 않는다”로 외우지 않는다. 핵심은 최종 층 patch output에 직접적인 supervision이 없다는 것이다.

26. CLIP의 맹점과 Mixture-of-Features

CLIP은 semantics(범주·개념·의미)에 강하지만 visual details(방향·수 세기·공간 배치)를 놓칠 수 있다. DINOv2처럼 다르게 표현하는 모델을 reference로 쓰면 맹점을 진단할 수 있다.

CLIP-blind pair:
cosCLIP(image₁,image₂) > 0.95
cosDINOv2(image₁,image₂) < 0.6

CLIP은 거의 같다고 보지만 DINOv2는 다르다고 보는 이미지 쌍이다. 차이를 묻는 질문을 만들어 MMVP benchmark로 평가한다. MoF=Mixture-of-Features는 기존 CLIP·DINOv2 등의 표현을 섞어 상보적인 정보를 얻는다. p.77은 additive MoF와 interleaved MoF(I-MoF)를 소개하며 세부 포착 개선을 보인다.

함정 “DINOv2 단독 점수가 낮으니 CLIP에 섞어도 소용없다”는 틀리다. 단독 성능과 정보의 상보성은 별개다.

Q06. “풀 속 컵”과 “컵 속 풀”을 구분하지 못한다면 어떤 보완이 필요한가?
모범답 단어 구성은 비슷해도 관계가 다른 hard negatives로 학습한다. 또 지역 위치 이해에는 image-level caption만으로 부족하므로 region caption·bounding-box 감독을 추가한다.

근거: 2강 pp.70–72

Q07. CoOp는 무엇을 학습하며, 새 클래스에 어떤 문제가 있는가?
모범답 Image/text encoder는 동결하고 클래스명 앞 context vectors를 학습한다. Base 클래스에 특화되어 novel 클래스에 과적합할 수 있다. 도메인 전이와 클래스 전이는 별개다.

근거: 3강 pp.10–18

Q08. CoCoOp의 조건부 문맥 식과 속도 단점을 설명하라.
모범답 π=hθ(f(x)), v_m(x)=v_m+π. 이미지 특징에서 생성한 meta-token으로 문맥을 바꿔 novel 일반화를 높인다. 이미지마다 text encoding이 달라 재사용이 어려워 학습이 느리다.

근거: 3강 pp.19–24

Q09. Pixel prompt, VPT-Shallow, VPT-Deep을 구분하라.
모범답 Pixel은 입력 이미지에 공통 픽셀 패턴을 더한다. VPT는 embedding prompt tokens를 첫 layer 입력에만(Shallow) 또는 여러 layer에(Deep) 삽입한다. Backbone 동결, VPT는 prompt와 task head 학습.

근거: 3강 pp.30–36

Q10. CoCoOp와 MaPLe에서 “조건화”되는 것은 무엇인가?
모범답 CoCoOp는 이미지 특징으로 text context를 조건화한다. MaPLe는 language prompt를 선형 coupling projection에 넣어 vision prompt를 조건화하며 양쪽에 deep prompting을 한다.

근거: 3강 pp.20, 40–41

Q11. Tip-Adapter의 query/key/value와 training-free의 의미는?
모범답 Query=test image feature, key=few-shot image features, value=one-hot labels. 유사도로 라벨을 가중합한 cache logits에 기존 CLIP logits를 더한다. Labeled data는 필요하지만 gradient 기반 추가 학습은 없다.

근거: 3강 p.48

Q12. 일반 fine-tuning과 FLYP의 목적함수 차이는?
모범답 일반 방식은 image encoder+linear head의 class CE. FLYP는 라벨을 caption으로 만들고 두 encoder 전체를 사전학습과 같은 image–text contrastive objective로 fine-tune한다.

근거: 3강 pp.49–54

Q13. ViLD-Image와 ViLD-Text의 학습 대상을 구분하라.
모범답 Image 경로는 detector region feature가 pretrained CLIP crop image feature를 따르게 L1 증류한다. Text 경로는 base class text와 region 유사도로 CE 분류한다. Region의 L2는 정규화, 손실은 L1이다.

근거: 3강 pp.59–60

Q14. ViLD가 novel 카테고리를 추론할 때 무엇을 교체하는가?
모범답 새 카테고리의 text embeddings를 만들어 region embedding과 비교한다. Class-agnostic localization은 공유한다. 새 클래스마다 detector 재학습을 요구하지 않는다.

근거: 3강 pp.57–64

Q15. Causal mask에서 미래 score를 −∞로 두는 이유는?
모범답 Softmax 뒤 미래 위치 확률을 0으로 만들어 정답 누출을 막기 위해서다. Score를 단순히 0으로 두면 exp(0)=1이라 가중치가 남는다.

근거: 4강 p.9

Q16. Token ID와 embedding의 차이, 토큰화의 비용 trade-off는?
모범답 ID는 vocabulary 인덱스, embedding은 lookup한 연속 벡터다. 토큰 단위가 크면 보통 시퀀스는 짧지만 어휘·embedding 파라미터가 커진다. Subword는 word/character의 절충이다.

근거: 4강 pp.15–27

Q17. Text-only GPT는 visual instruction 데이터를 어떻게 만드는가?
모범답 이미지 캡션·객체 종류·bounding boxes를 텍스트 context로 읽고 instruction/output을 생성한다. 원래 이미지와 합쳐 image–instruction–answer triplet을 만든다. 원시 픽셀을 직접 입력받는 방식이 아니다.

근거: 4강 pp.40–43

Q18. LLaVA의 3요소와 penultimate patch features를 쓰는 이유는?
모범답 Vision encoder(CLIP) + projector + LLM. CLS 하나는 전역 요약이고 최종 patch outputs에는 직접 대조 감독이 없어서, 끝에서 두 번째 층 patch features로 공간·세부정보를 보존해 LLM에 전달한다.

근거: 4강 pp.47–55

Q19. LLaVA Stage 1/2에서 어떤 모듈을 학습하는가?
모범답 Stage 1은 projector만 학습하고 vision+LLM 동결. Stage 2는 projector+LLM을 학습하며 vision은 계속 동결한다. 답변 언어 토큰의 autoregressive loss를 쓴다.

근거: 4강 pp.54–57

Q20. DINOv2 단독 성능이 낮아도 MoF에서 도움이 될 수 있는 이유는?
모범답 단독 성능과 특징의 상보성은 다르다. CLIP의 의미 중심 표현이 놓친 방향·수·배치 같은 시각 정보를 DINOv2 표현이 보완할 수 있다.

근거: 4강 pp.69, 74–77

Q21. CLIP-blind pair의 조건과 평가 목적은?
모범답 CLIP cosine>0.95, DINOv2 cosine<0.6인 이미지 쌍. CLIP이 놓치는 시각 차이를 찾고 MMVP 질문으로 지각 한계를 평가한다.

근거: 4강 pp.74–77

Q22. Q-Former, concat-projection, PruMerge를 구분하라.
모범답 Q-Former는 지정 수 query로 시각 정보를 압축. Concat은 이웃 4개→projection 1개. PruMerge는 중요 token sample→kNN cluster→weighted average merge.

근거: 4강 pp.80–82

Q23. GUI token reduction에서 selection과 위치 보존이 중요한 이유는?
모범답 UI는 구조·중복이 많지만 클릭할 좌표가 중요하다. UI graph로 중복 토큰을 선별하면서 원래 위치 관계를 보존한다. 슬라이드의 merging은 취소선이다.

근거: 4강 pp.83–86

Q24. SoM의 두 필수 조건과 마크를 덧씌우는 순서는?
모범답 의미 region 분할로 텍스트와 grounding하고, mark가 해석·언어 참조 가능해야 한다. 작은 region부터 큰 region 순으로 overlay하며 이전에 표시한 영역을 제외한다.

근거: 4강 pp.91–94

OX 10문항

정답 글자만 맞히지 말고 틀린 문장을 올바르게 고쳐 본다.

1. CLIP은 이미지의 캡션 문장을 한 단어씩 생성하는 손실로 학습한다.
X · 배치 내 이미지–텍스트 짝을 맞추는 contrastive loss.
2. Zero-shot은 사전학습도 하지 않았다는 뜻이다.
X · 목표 과제 라벨을 이용한 추가 학습이 없다는 뜻.
3. SigLIP은 전역 softmax를 없애므로 음성쌍도 쓰지 않는다.
X · 각 쌍을 양성/음성으로 이진 학습한다.
4. CoOp의 도메인 전이 성공은 novel class 성능도 높다는 증거다.
X · 도메인 변화와 클래스 변화는 다른 축.
5. MaPLe는 두 encoder 전체의 가중치를 업데이트해야 한다.
X · Backbone은 동결하고 prompts와 coupling을 학습.
6. Training-free Tip-Adapter에도 labeled few-shot 예시는 필요하다.
O · 그 예시로 feature/label cache를 만든다.
7. ViLD는 L2 distillation loss를 사용한다.
X · L2는 정규화이고 image distillation은 L1.
8. LLaVA Stage 2의 end-to-end는 vision encoder도 학습한다는 뜻이다.
X · 해당 강의 recipe는 vision 동결, projector+LLM 학습.
9. PruMerge의 결과는 원래 visual token의 25%만 사용하는 것이다.
O · 75% 감소이며 25% 감소와 다르다.
10. SoM의 핵심은 의미 영역과 말로 지칭 가능한 표식이다.
O · Region grounding + interpretable/speakable marks.

계산 연습 3개

강의의 식과 구조에서 만든 설명용 연습문제다.

1. CLIP 배치 N=4이고 모든 Sᵢⱼ가 같다. 양성/음성 개수, 정답 확률, 평균 손실은?
양성 4, 음성 12. 정답 확률 1/4. 각 방향 CE=ln4, 양방향 평균도 ln4≈1.386. 합이 아니라 평균이므로 2ln4가 아니다.
2. d_model=4096, |V|=32000이면 input embedding 파라미터 수는?
4096×32000=131,072,000개. 이 embedding 행렬만의 수이며 모델 전체 파라미터 수가 아니다.
3. 시각 토큰 576개를 25%만 쓰면 몇 개인가? 전체 attention 길이 L까지 1/4이 되었다고 가정하면 L² 항의 비율은?
시각 토큰은 144개, 432개 감소. 가정 아래 L² 항은 1/16. 실제 L에는 텍스트도 있고 다른 연산도 있어 전체 추론 시간 1/16을 보장하지 않는다.
